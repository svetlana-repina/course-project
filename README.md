# Курсовой проект по программированию
## Основная информация:

### Тема проекта: Проектирование системы для проведения пошаговых RPG-боев с выбором класса персонажа.
### Автор проекта: Репина С.С.
### Группа: ПИ-52

## Краткое описание проекта:

### Консольная программа позволяет игроку вести пошаговые сражения с компьютером или с другим игроком. Она рассчитывает нанесённый и получаемый урон, учитывает защиту, критические удары, расход маны и выносливости. Программа создана для любителей игр и позволяет протестировать боевые механики.

## Запуск и сборка программы:

### Сборка: g++ *.cpp -o app
### Запуск: ./app
